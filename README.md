# Github_demo_critical_thinking
نشاط للطلاب في شعبة مهارات البحث والتفكير النقدي بعد العرض التقديمي

في خلال محاضرات الاسبوع السادس للدوام كل مجموعة عملت عرض تقديمي عن اداة تعليمية
مجموعتنا شرحت عن github 
وبعد العرض فيه نشاط سريع خفيف للطلاب الحاضرين
بدنا كل طالب يدخل على هاي الrepository ويعمل تعديل عليها
اولا :يدخل الرابط على الrepository عن طريق الQR المعروض قدامهم
ثانيا :يدخل على ملف الاكلة المفضلة ويعمل ملف جديد جوا الملف ويسمي باٍسم اكلتو المفضلة
ثالثا :يكتب جوا الملف اسمو وتاريخ اليوم 
رابعا :قبل ما يعمل commit للتغيير يعمل preview للتغيير ويتأكد انو اللي عملو صح
خامسا :يعمل commit للتغيير وبهيك بكون خلص النشاط
